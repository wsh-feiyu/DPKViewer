# DPKViewer

寻仙 DPK 包（`whpackage1.0`）图形化工具：浏览、解包、打包、对比、原位导入，附带完整命令行模式。
MFC 静态链接单文件 exe，无需运行库依赖。

当前版本：**v0.1.5**

---

## 功能总览

### 浏览

- 打开 `.dpk` 包，列表显示条目路径、根块号、块链长度、明文/存储大小、压缩加密标志、MD5 校验状态（虚拟列表，大包流畅滚动）；
- **文件夹收纳视图**（默认开）：按目录分组浏览，双击进入文件夹、首行 `..（返回上层）` 返回；取消勾选恢复全路径平铺列表；
- **筛选**：全包范围按路径子串即时搜索；
- 选中条目在下方查看流头字段（flags / 明文 / 存储大小）与 MD5 校验结果；
- **双击 / 右键「查看」**：打开查看窗口——文本直接显示（状态栏标注编码：UTF-8 / GBK(ANSI)，UTF-8 BOM 自动跳过），二进制按十六进制转储；解码乱码自动切换十六进制；文本 / 十六进制可手动切换。

### 导出 / 导入

- **解包到目录**：全部条目导出并逐条校验 MD5，单条失败不影响其余，Esc 可取消；
- 右键**导出文件**：单条目导出；
- 右键**导出文件夹**：递归导出某文件夹下所有条目，保持包内目录结构；
- 右键**导入文件到此处**：把磁盘文件导入到选中文件所在目录（同名替换、否则新增）。
  采用**原位补丁**：只改写该条目的块，其余条目字节不动——不解码无关条目、不缓存整包，
  内存占用 ≈ 导入文件大小，5GB 大包同样适用，且有块布局扫描进度提示（Esc 可取消）。

### 生成 DPK 包

- 选择源文件夹与输出路径，可选压缩（zlib）/加密；
- **自适应压缩**：与游戏原始打包器一致的逐条目策略——压缩不小于原文时按原样存储（`0x02` 仅加密），否则压缩（`0x03` 压缩+加密）；
- **沿用已打开包的包头（模板模式）**：以原包 1024 字节包头为模板、按原包块号回填；
  内容未变的条目**字节级复用原包数据**（flags、压缩输出、MD5 全部保持原样），
  条目按原包目录树顺序写入——原样重打包可做到包大小与原包分毫不差、对比零差异。

### 包对比

- 菜单「工具 → 对比 DPK 包」打开对比窗口；
- **三档深度**：
  | 深度 | 说明 |
  |---|---|
  | 仅路径 | 只比条目清单（增/删），最快 |
  | 标准（推荐） | 路径 + 流头字段 + 内嵌 MD5 摘要，每条目只读根块 1KB |
  | 完整 | 逐条目解码并逐字节比对，可检出包内损坏 |
- **大小差异上限**（默认 100MB，可自定义或「不限制」）：两包大小差异超限时提示并停止，防止误选文件；
- 结果按状态筛选：全部 / 仅差异 / **仅内容不同** / 仅 A / 仅 B / 仅相同；
- **双击「不同」条目打开内容对比**：
  - 文本：行级 diff（相似行自动配对，部分修改的行不拆分成两侧独有），行号显示、行内差异橙色高亮、修改行黄 / A 独有红 / B 独有绿，两侧滚动同步（垂直 + 水平像素级），「隐藏相同行」把连续相同段折叠为一行；
  - 非文本：十六进制逐字节对齐，差异字节高亮；
- 支持导出 UTF-8 文本报告。

## 命令行模式

同一 exe，不弹界面。支持 `/help` `--help` `help` `/?` `-?` `--?` `-h` 查看帮助。

```
DPKViewer.exe /list    <包>                        列出包内条目（根块/明文/存储/标志）
DPKViewer.exe /extract <包> <目录>                 解包全部条目到目录（逐条校验 MD5）
DPKViewer.exe /pack    <源目录> <输出包>           打包目录为 DPK 包
    选项: /level N(1-9) /nocompress /noencrypt /template <包>(沿用原包布局,未变条目原样复用)
DPKViewer.exe /compare <包A> <包B>                 对比两个包
    选项: /paths|/meta|/full(对比深度) /maxdiff <MB>(大小差异上限,超出停止)
DPKViewer.exe /help | --help | help | /?           显示帮助
通用选项: /log <文件>(同时写日志,UTF-8) /quiet(不写控制台)
退出码: 0 成功(对比时=无差异) / 1 失败或有差异
```

exe 为控制台子系统：cmd / PowerShell / Windows Terminal / 脚本与 AI 助手的管道调用都能直接拿到输出；双击启动进入 GUI（控制台窗口自动关闭）。

## 包格式速览

详细格式与读写语义见 [`docs/DPK_FORMAT.md`](docs/DPK_FORMAT.md)，以参考实现 `dpk.py` 为准。

- 容器：`whpackage1.0`，固定 1024 字节块，块链（根块 32 字节头 / 续块 8 字节头）组织虚拟文件；
- 条目流：`whsc1.0`，48 字节流头含 flags / 明文大小 / 存储大小 / **明文 MD5 摘要**；
- flags：`0x01` 压缩（zlib）、`0x02` 加密（DES 变体：CBC 零 IV + 尾块混淆，密钥取口令前 8 字节）、`0x04` 内容口令；
- 两条系统虚拟文件：目录树（treeRoot）与路径名表（namesRoot）。

> ⚠️ **做任何更改前，确保已备份！** 原位导入直接改写包文件，无事务保护。

## 构建

依赖 Visual Studio 2022（v143 工具集，含 MFC）：

```
tools\build_app.bat Release x64
```

产物：`build\x64\Release\DPKViewer.exe`（MFC/CRT 静态链接，LTCG 全程序优化）。

CI：GitHub Actions（见 `.github/workflows/`）。

## 目录结构

```
src/DPKViewer/App/    界面层：主窗口、对比窗口、内容对比、查看窗口、命令行
src/DPKViewer/Core/   核心层（不依赖 MFC）：读写器、whsc 编解码、DES、MD5、zlib、diff、文本工具
res/                  资源：菜单、图标、manifest
tests/                独立探针与自测（DES/Var/TextDiff/Tree/Patch 等）
tools/                构建脚本、图标生成、GUI e2e 脚本
docs/                 格式文档（DPK_FORMAT.md / DESIGN.md）
```
